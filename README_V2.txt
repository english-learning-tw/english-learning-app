English Learning V2 - 動態教材管理系統（本機測試版）

內建教材：23 個原始英文學習 HTML 頁面，保留各自互動功能。
新增功能：HTML 上傳／替換、本機教材目錄、單字新增／修改／刪除、IPA、中文、例句、分類、語音播放、JSON 備份與匯入。

開始使用：
1. 解壓縮所有檔案，切勿只開啟單一 HTML。
2. 電腦安裝 Python 後，在解壓縮目錄執行：python -m http.server 8000
3. 瀏覽器打開 http://localhost:8000
4. 點「管理後台」上傳 HTML 或建立單字；點「教材」或「單字庫」測試。
5. 要在手機安裝 PWA，請先將整個資料夾部署至 HTTPS 網站，例如 Firebase Hosting / Netlify / GitHub Pages，再於手機瀏覽器打開網址並加入主畫面。

重要限制：
- 上傳／編輯儲存在「操作中的裝置」IndexedDB，不會自動上傳至公開網站或其他手機。
- 其他手機僅會看到一起部署的 23 份內建教材，不會看到你在管理後台新增的內容。
- 要讓全體使用者同步新增教材，必須後續接雲端後端、管理員登入、檔案儲存、發布版本與權限驗證。
- HTML 上傳在 iframe sandbox 中隔離，但仍只建議匯入可信任的檔案。原教材可能依瀏覽器的發音引擎及 sandbox 權限而有差異。
- 單字編輯作用於 V2 自訂單字庫，不會修改既有 HTML 內嵌的單字資料。更改既有 HTML 教材請上傳新的完整 HTML 替換。
- 本版本不含雲端服務、不含管理員認證、無正式公共發布權限。

雲端同步建議：
- Hosting：Firebase Hosting
- 登入：Firebase Authentication，管理員自訂權限（須後端驗證）
- 資料：Cloud Firestore（課程目錄 / 單字 / 發布版本 / 最後更新時間）
- 檔案：Cloud Storage（HTML 原始檔；以安全域名隔離呈現）
- 安全：雲端儲存規則、伺服器端檔案檢查、上傳大小限制、管理者批准發布、版本回滾
- 使用者 App：線上取得已發布目錄及更新，離線緩存；同步收藏紀錄需另外加入使用者帳號。
