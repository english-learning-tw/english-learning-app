English Learning PWA 整合版

1. 將資料夾內所有檔案原樣上傳至可公開透過 HTTPS 存取的靜態網站主機（例如 GitHub Pages、Netlify、Cloudflare Pages）。
2. 開啟 https 網址首頁並測試各主題頁、英文發音、收藏及單字卡。
3. iPhone 使用 Safari 分享 > 加入主畫面；Android Chrome 選安裝應用程式 / 加入主畫面。
4. 把 https 網址傳給朋友，對方也可安裝。
5. 離線快取及發音支援會依瀏覽器和裝置有所不同。

注意：這是既有 HTML 學習頁的整合入口，不是已上架 App Store / Google Play 的原生 App，也尚未設置網站網址。各主題收藏與學習紀錄為原始 HTML 各自儲存，沒有跨裝置同步。
